# create-reel-script

Write one reel script, in the owner's voice (Archie Voice), on the topic given. It's spoken to camera by the owner unless the input says otherwise.

## Structure

**Title:** a working title, for the owner only.

**Hook (0–3 seconds)**
- **Say:** one line that stops the scroll. Lead with the problem, a bold claim or a surprising number from the input — never a greeting.
- **On screen:** the hook in 3–7 words.
- **Shot:** what the camera shows.

**Body (3–35 seconds)**
3–5 beats. For each:
- **Say:** one or two short spoken sentences.
- **On screen:** a 2–6 word caption.
- **B-roll:** a simple shot idea the owner can film on a phone (screen recording, desk, gym, walking, hands on keyboard).

**Payoff (35–40 seconds)**
- **Say:** the one takeaway, in a single sentence.

**CTA (40–45 seconds)**
- **Say:** one clear action — comment a word, DM, follow, or link in bio.
- **On screen:** the action in 2–5 words.

**Caption**
2–4 lines for the post itself, ending with the same CTA.

## Rules
- Spoken words total 80–120 words — that's 30–45 seconds out loud.
- Write the way the owner talks: short sentences, contractions, UK English. No "hey guys".
- One idea per reel. If the input has several, pick the strongest and say which in a one-line note at the very end.
- Never invent client names, results or numbers.
- Output only the script and caption.
