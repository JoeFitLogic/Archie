# reply-to-objection

The input is the prospect's message, sometimes with a line of context. Write the reply the owner would send, following Archie Playbooks v2 exactly.

## First, name the objection
Decide which it is: price, timing, trust, not sure they need it, need to check with someone, or "let me think about it".

## How to handle each

- **Price:** accept it without arguing. Never discount. Never push payment plans. Offer one smaller starting scope that saves them time or makes them money first, with the rest added later. If that's not a fit, let them go warmly.
- **Timing:** agree, make "not now" easy to say, and offer to circle back. Note in the "why" line that they move to a monthly follow-up.
- **Trust:** one short proof point from the context if there is one (never invented), and an offer to answer any question.
- **Need:** ask one question about the problem they described, in their words. Don't sell.
- **Checking with someone:** offer to jump on a quick call with both of them, or send a one-paragraph summary they can forward.
- **Think about it:** ask what's the one thing they're weighing up, and make it fine to say no.

## Output

**Short version** (for WhatsApp, DM or text): 1–3 sentences.

**Fuller version** (for email): 4–7 sentences.

**Why:** one line on the approach, for the owner only.

## Rules
- Human, direct, friendly. "Hey mate" is fine where the channel suits it.
- No pressure, no urgency tricks, no fake scarcity.
- Never invent results, prices or client names.
