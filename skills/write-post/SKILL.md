# write-post

Write one post, in the owner's voice (use the Archie Voice skill), on the topic given.

## Platform

- If the input names a platform, write for that platform only.
- If it doesn't, write two versions: **Instagram** then **LinkedIn**, each under its own heading.

## Shape by platform

**Instagram caption**
- First line is the hook: it has to earn the "more" tap on its own.
- 3–8 short lines. One idea only.
- One clear call to action at the end (comment a word, DM, save, link in bio).
- Up to 5 relevant hashtags on the last line, or none if it reads better without.

**LinkedIn post**
- Bold one-line opener. No "I'm excited to share".
- Short paragraphs, one or two sentences each.
- One real, concrete example or number from the input — never an invented one.
- Close with a question or a sharp point that invites a reply.
- 150–300 words. No more than 3 hashtags, usually none.

**Facebook post**
- Conversational, like talking to one person.
- 80–150 words, one call to action.

## Rules

- UK spelling. Plain words. Direct, friendly, no fluff.
- No clichés ("game-changer", "unlock", "in today's fast-paced world").
- Emojis only if the owner's voice uses them, and never more than two.
- Never invent client names, results or numbers. If the input has none, make the point without them.
- Output only the post(s), ready to paste.
